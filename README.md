# 안녕하세요, suyoung입니다 👋

**백엔드 개발과 AI 응용 서비스 구현에 관심이 있는 컴퓨터공학 전공자입니다.**

Spring Boot와 Node.js로 API·데이터베이스·인증 기능을 구현하고, SwiftUI로 iOS 서비스도 개발했습니다. 구현 과정에서 발생한 문제를 단계별로 확인하고 개선한 내용을 프로젝트에 기록하고 있습니다.

## 기술 스택

- **Backend** — Java, Spring Boot, Spring Security, JPA, Node.js, Express
- **Database** — MySQL, Cloudflare D1 (SQLite)
- **App / Web** — Swift, SwiftUI, JavaScript, HTML, CSS
- **AI / Data** — Python, scikit-learn, Claude API
- **Deployment / Embedded** — Docker, Cloudflare Workers, C, uC/OS-II
